# Kebijakan istilah teknis

Jika Anda ragu memakai istilah Inggris atau padanan Indonesia, baca berkas ini. Pembaca harus memahami istilah itu dalam satu kali baca. Padanan resmi yang tidak dikenal pembaca tidak memenuhi tujuan itu.

Bahasa Sederhana membagi istilah menjadi tiga kelompok. Daftar di bawah adalah contoh, bukan daftar lengkap. Padanan resmi berubah dari waktu ke waktu. Untuk istilah lain, cari padanannya di Pasti (pasti.kemdikbud.go.id) dan bentuk bakunya di KBBI (kbbi.kemdikbud.go.id).

## Kelompok B: pertahankan istilah asing

Padanan resmi untuk istilah ini ada, tetapi belum dikenal luas. Dalam Mode Sederhana, pakai istilah asing dan tulis miring pada pemakaian pertama di setiap dokumen, kecuali di dalam kode. Istilah yang umum, misalnya host, port, flag, dan path, boleh ditulis tegak. Dalam Mode Baku, pakai padanan resmi dan tulis istilah asing dalam kurung pada pemakaian pertama.

| Istilah asing | Padanan resmi (untuk Mode Baku) |
|---|---|
| *server* | peladen |
| *cache* | tembolok |
| *firewall* | tembok api |
| *browser* | peramban |
| *email* | surel |
| *bug* | pepijat (periksa di Pasti) |
| *cluster* | klaster |
| *framework* | kerangka kerja |
| *deploy*, *commit*, *branch*, *merge*, *pull request* | tidak ada padanan yang mapan, tetap dipakai |
| *build*, *runtime*, *framework* | tidak ada padanan yang mapan, tetap dipakai |
| *endpoint*, *webhook*, *bucket* | tidak ada padanan yang mapan, tetap dipakai |
| *container*, *pod*, *instance*, *job* | tidak ada padanan yang mapan, tetap dipakai |
| *backend*, *frontend* | tidak ada padanan yang mapan, tetap dipakai |

Jika istilah kelompok B dipakai sebagai kata kerja dengan imbuhan, pakai tanda hubung sesuai EYD V: di-*deploy*, men-*deploy*, di-*commit*. Jika ada kata kerja Indonesia yang jelas, pakai kata kerja itu. Dalam kalimat perintah, istilah asing boleh dipakai tanpa imbuhan: "*Commit* perubahan Anda."

## Aturan pakai

1. Satu istilah, satu bentuk. Jika Anda memilih *server*, jangan menulis "peladen" di bagian lain.
2. Jangan menjelaskan istilah kelompok A dan C. Jelaskan istilah konsep dari kelompok B pada pemakaian pertama, kurang dari sepuluh kata: "*cache* (salinan data sementara untuk mempercepat baca)".
3. Nama produk, nama perintah, dan label UI tidak diterjemahkan dan tidak dimiringkan. Tulis label UI persis seperti di layar, di dalam tanda petik terbalik: klik `Save`, atau klik `Simpan` jika antarmukanya berbahasa Indonesia.
4. Singkatan teknis umum (API, URL, HTTP, CLI, SQL) tidak dijelaskan dan tidak dimiringkan.
5. Jangan menyerap istilah secara asal: "mengupdate", "mendownload", dan "diinstall" bukan bentuk baku. Tulis "memperbarui", "mengunduh", dan "dipasang" atau "diinstal".
