# Padanan kata: dari gaya AI ke bahasa sederhana

Tabel ini milik Bahasa Sederhana, bukan daftar resmi Badan Bahasa. Tabel ini memetakan kata yang sering dipakai berlebihan dalam dokumen buatan AI ke pengganti yang sederhana. Jika sebuah kata tidak membawa fakta, hapus kata itu, jangan diganti.

## Kata dan frasa gaya AI

| Gaya AI | Tulis ini |
|---|---|
| memanfaatkan, mendayagunakan | pakai, memakai |
| dalam rangka, guna | untuk |
| sebelum melakukan | sebelum |
| memastikan, menjamin (sebagai hiasan) | pastikan (atau hapus) |
| perlu dicatat bahwa, penting untuk diingat, patut digarisbawahi | (hapus, lalu nyatakan faktanya) |
| sangat, benar-benar, sungguh, amat | (hapus) |
| dengan mudah, dengan cepat, secara mulus, tanpa repot, tanpa hambatan | (hapus, atau beri angkanya) |
| tangguh, andal, canggih, mutakhir, komprehensif, kuat (untuk sistem) | (hapus, atau sebut sifat yang dapat diukur) |
| fungsionalitas | fungsi, fitur |
| memungkinkan Anda untuk | Anda dapat |
| dirancang untuk, bertujuan untuk | (hapus, lalu katakan apa yang dilakukannya) |
| memfasilitasi | membantu |
| menyelami, mendalami, mengeksplorasi | membaca, memeriksa |
| dalam hal, terkait dengan, berkaitan dengan | untuk, tentang |
| dalam hal terjadi, apabila terjadi | jika |
| dikarenakan, disebabkan oleh fakta bahwa | karena |
| sesuai kebutuhan, jika diperlukan | (sebut syaratnya) |
| dan/atau | pilih satu, atau tulis "X, Y, atau keduanya" |
| dll., dsb., dst. | (sebut butirnya) |
| menangani dengan baik | (katakan apa yang dilakukannya: "mencoba lagi tiga kali, lalu berhenti") |
| langsung bisa dipakai, siap pakai | secara bawaan |
| di balik layar | secara internal |
| super cepat, kilat | cepat (beri angkanya) |
| merampingkan, menyederhanakan alur | membuat lebih sederhana, membuat lebih cepat |
| segudang, beragam, berbagai macam | banyak |
| mengatasi masalah, menjawab tantangan | memperbaiki kesalahan |
| krusial, vital, esensial, fundamental, sangat penting | penting (atau hapus) |
| lanskap, ranah, ekosistem (kiasan) | bidang |
| permadani, simfoni, sinergi | (hapus) |
| inovatif, revolusioner, terobosan, terdepan | baru (atau hapus) |
| transformatif, mengubah permainan | (hapus, lalu katakan apa yang berubah) |
| menavigasi (kiasan) | buka, pakai |
| menonjolkan, menggarisbawahi, menekankan | menunjukkan |
| mendorong, memberdayakan, memperkuat | membantu, mendukung |
| meningkatkan (tanpa angka) | (beri angkanya, atau hapus) |
| lebih lanjut, terlebih lagi | selain itu |
| kesimpulannya, sebagai kesimpulan, secara keseluruhan, pada akhirnya | (hapus) |
| di era digital saat ini, di dunia yang serba cepat | (hapus) |
| memainkan peran penting, berperan krusial | (nyatakan faktanya) |
| mari kita, yuk | (hapus) |
| tidak dapat dimungkiri bahwa | (hapus) |
| semoga membantu, jangan ragu untuk bertanya | (hapus) |

## Kata tidak baku

| Tidak baku | Baku menurut KBBI |
|---|---|
| merubah, dirubah | mengubah, diubah |
| mempengaruhi | memengaruhi |
| mengkonfirmasi, mengkonfigurasi | mengonfirmasi, mengonfigurasi |
| silahkan | silakan |
| resiko, praktek, analisa, sistim | risiko, praktik, analisis, sistem |
| aktifitas, kwalitas, ijin, nasehat | aktivitas, kualitas, izin, nasihat |
| obyek, subyek, standarisasi | objek, subjek, standardisasi |
| sekedar, jaman, kadaluarsa | sekadar, zaman, kedaluwarsa |
| diatas, dibawah, didalam, diluar | di atas, di bawah, di dalam, di luar |
| disini, disana, dimana, kemana | di sini, di sana, di mana, ke mana |
| terimakasih | terima kasih |
| mengupdate, mendownload, diupload | memperbarui, mengunduh, diunggah |
| memperbaharui, pembaharuan | memperbarui, pembaruan |
| apapun, siapapun, seringkali | apa pun, siapa pun, sering kali |
| otentikasi, nomer, metoda, frase | autentikasi, nomor, metode, frasa |
| menginstall, diinstall | menginstal, diinstal (atau memasang, dipasang) |
| anda | Anda |

## Terjemahan harfiah dari bahasa Inggris

| Terjemahan harfiah | Tulis ini |
|---|---|
| server di mana aplikasi berjalan | *server* tempat aplikasi berjalan |
| fitur yang mana dipakai | fitur yang dipakai |
| melakukan instalasi, melakukan pembaruan | memasang, memperbarui |
| melakukan pengecekan, melakukan verifikasi | periksa, atau pastikan |
| membuat perubahan | mengubah |
| memberikan dukungan | mendukung |
| mengambil tempat | terjadi |
| mengalami kegagalan, mengalami penurunan | gagal, turun |
| adalah merupakan | adalah, atau merupakan (pilih satu) |
| agar supaya, demi untuk | agar, untuk |
| sangat cepat sekali | cepat (beri angkanya) |
| para pengguna-pengguna | para pengguna, atau pengguna |

| dalam rangka untuk | untuk |
| di dalam hal ini | dalam hal ini, atau hapus |
| oleh karena itu maka | oleh karena itu |
